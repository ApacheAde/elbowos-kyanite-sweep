# Kyanite Sweep

Full-colour Python 3 neon minesweeper arcade for [ElbowOS](https://x.com/ElbowOS).

Clear an 8×10 kyanite lattice. Hidden void charges sting.
Numbers count neighbouring charges. Flag the rest.

Arrows move. Space / Enter open. F flag. R reset.

## Play

```
pip install -r requirements.txt
python3 kyanite_sweep.py --play
```

## Record a 9:16 reel

```
python3 kyanite_sweep.py --record
```
